# TRUNFO Shop · regras do projeto

Produto da Bel Valle para sellers de TikTok Shop na Europa (e Brasil depois).
Fonte de verdade do produto: "TRUNFO Shop · Blueprint v2.0 Europa".

## Regras de produto (não negociáveis)

- Nunca inventar taxas, comissões, benchmarks ou câmbios. Taxas da plataforma são escritas pelo seller a partir do Seller Center. O IVA vem pré-preenchido com a taxa normal do país e é sempre editável.
- Nunca prometer resultados, distribuição ou ausência de penalizações.
- Não usar "TikTok" no nome, logótipo ou identidade. Mostrar sempre que é uma ferramenta independente.
- Sem scrapers do Creative Center nem de outras plataformas. Só APIs oficiais e conteúdo curado.
- Não usar materiais do trabalho da Bel no TikTok (Avatar, playbook BR, glossário entregue). Conteúdo escrito de raiz.
- Nunca pedir senhas do Seller Center. Dados de cada loja separados (RGPD).
- Textos em pt-PT para Portugal; outras línguas só com revisão humana nativa.

## Stack

- Next.js (App Router) + TypeScript + Tailwind v4.
- Supabase: projeto `trunfo-shop` (ref ddwabohwcchlpllttxyn, eu-west-3, Paris). Ainda não usado no MVP.
- Deploy: Vercel.
- Lógica de cálculo em `lib/` com testes (`npm test`).
