# TRUNFO Shop

A próxima jogada da sua loja no TikTok Shop. Uma ferramenta Bel Valle.

## O que já existe

- **Calculadora de margem real** (`/calculadora`): lucro por venda, CPA máximo e ROI mínimo, por país, com IVA, comissões, afiliado, portes, devoluções e anúncios.
- **Métricas explicadas** (`/metricas`): GMV, CTR, CVR, GPM, ROI, CPA e outras, em linguagem de lojista.

## Correr localmente

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # testes da calculadora
npm run build
```

Regras do projeto em `AGENTS.md`.
